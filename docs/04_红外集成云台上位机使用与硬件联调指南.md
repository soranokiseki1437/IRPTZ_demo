# 红外集成云台目标跟踪上位机使用与硬件联调指南

## 一、 系统简介与部署状态

本项目已在 `D:\IRPTZ_demo` 目录下完全构建完成。
相较于旧版 `D:\RGB_PTZ_demo`（可见光 + 串口 Pelco-D 云台），本上位机实现了全以太网化改造与红外热成像专属功能的深度集成：

1. **通信架构全面升级**：
   - 彻底摒弃 RS-485 串口与 Pelco-D 协议转换器，改用 **以太网一体化控制**（基于 `SV_NET_SDK.dll`）。
   - 视频拉流使用 FFmpeg 8.1 低延迟 RTSP 流拉取（TCP 传输 + 50ms 超低抖动缓冲）。
   - 保留原有的多线程解码 (`DecodeThread`)、录像线程 (`RecordThread`) 与截图引擎。

2. **核心跟踪算法 100% 传承**：
   - 保留完整的 **DSST (Discriminative Scale Space Tracker)** 尺度自适应相关滤波核心算法。
   - 保留 **卡尔曼滤波 (Kalman Filter)** 运动状态估计与航迹预测器。
   - 保留 **位置式/增量式 PID 闭环伺服控制器** 与死区控制逻辑。

3. **新增红外热成像专属功能**：
   - **一键快门校正 (FFC)**：支持主动触发非均匀性快门校正；内置 **500ms 伺服自动冻结保护**，避免快门闭合卡顿导致 PID 积分饱和甩头。
   - **多色板自由切换**：支持白热 (White Hot)、黑热 (Black Hot)、铁红 (Ironbow)、彩虹 (Rainbow) 等模式切换。
   - **全屏测温 HUD 悬浮显示**：实时轮询全画幅最高温/最低温，并在视频预览画面右上角以半透明 HUD 叠加显示。

## 三、 硬件联调与操作步骤

### 1. 网络连接与参数设置
1. 将电脑网卡设置在与红外相机同一局域网网段（例如红外相机默认 IP 为 `192.168.1.64`，电脑网卡可设为 `192.168.1.100`）。
2. 在上位机界面右上角“红外相机连接”面板中输入：
   - **IP 地址**：例如 `192.168.1.64`
   - **端口**：默认为 SDK 登录端口（一般为 `8000` 或 `37777`，可在相机说明书确认）
   - **用户名**：默认 `admin`
   - **密码**：相机登录密码
3. 点击 **【连接相机】** 按钮：
   - 系统将自动通过 `SV_NET_SDK` 登录设备；
   - 自动启动 RTSP 视频流并在中央窗口播放红外画面；
   - 自动绑定并激活以太网集成云台控制通道；
   - 启动 100ms 角度自动查询与 1Hz 画面测温数据更新。

### 2. 云台手动测试
- 使用界面上的八向方向盘按钮（上、下、左、右、左上、右上、左下、右下）测试转动；
- 滑动调节云台速度（0~63 对应 Pelco 规范）；
- 观察左下角【角度/速度显示】及【Hex数据监控仪】中的实时 TX/RX 指令包；
- 确认云台水平角度 (0~360°) 与俯仰角度 (-40°~40°) 能够实时回传。

### 3. 红外功能测试
- **切换色板**：在“红外专用控制”区域的色板下拉框中切换【白热】、【黑热】、【铁红】、【彩虹】；
- **一键校准 (FFC)**：点击【一键快门校正 (FFC)】，可听到相机硬件快门“咔哒”一声，画面校准刷新；
- **温度 HUD**：勾选【显示测温 HUD】，屏幕右上角即刻显示最高温与最低温数值。

### 4. 目标跟踪测试
1. 在视频画面就绪后，点击 **【选择目标】**（或按快捷键 `Space`）；
2. 在视频画面中按住鼠标左键并拖动，框选待跟踪的目标（如车辆、人体或发热物体）；
3. 松开鼠标后点击 **【开始跟踪】**：
   - 画面中将出现绿色跟踪十字与目标边框；
   - DSST 算法将实时计算目标尺度与位置；
   - 卡尔曼滤波器对目标运动轨迹进行滤波预测；
   - PID 控制器自动向以太网云台发送运动速度指令，使目标保持在画面中心；
4. 点击 **【停止跟踪】** 或按 `Esc` 键退出跟踪模式。

## 四、 常见问题排查 (FAQ)

| 现象 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| 点击连接相机提示失败 | IP 地址不通或端口错误 | 1. 检查物理网线及网口指示灯；<br>2. 用 `ping <IP>` 测试连通性；<br>3. 检查相机的网络端口配置。 |
| 画面黑屏无视频流 | RTSP URL 路径或端口不匹配 | 检查相机 RTSP 流地址规则（例如主码流 `rtsp://<IP>:554/live/ch0`），可在 `config.ini` 中自定义调整。 |
| 云台方向相反 | 云台机械反装或轴极性不同 | 可在 `netptzcontroller.cpp` 的 `moveDirection` 函数中微调方向位掩码。 |
| 无法获取云台实时角度 | 相机固件未开放绝对坐标查询接口 | `NetPtzController` 内置了连续10次查询失败自动平滑降级机制，不会阻断跟踪和控制。 |
| 跟踪过程中偶尔丢目标 | 红外低对比度或快门校准打断 | 1. 确保使用白热或黑热模式以获得最高对比度；<br>2. 软件已在 FFC 触发时自动暂停 PID 伺服 500ms，避免快门卡顿导致云台甩动。 |
